# 1. CSV as the canonical source for coalition commitments

The coalition tracker was originally maintained in a Google Sheet, with the CSV at `src/data/data.csv` generated by manual export on each deploy. With the introduction of an AI-assisted research loop that edits commitment data directly, the CSV is now the canonical source of truth and the Google Sheet is an optional view maintained via import/export. The AI edits the CSV in place, and the user reviews changes via `git diff` against a dated markdown report.

## Consequences

- The README and `Footer.tsx` Google Sheet link may need to be re-described as "view only" or removed; the CSV is what the build reads.
- Manual edits to the canonical data go through the CSV, not the Google Sheet.
- The build pipeline is unchanged.
- Resume is supported via a gitignored `state.json` next to the skill, not via the `Updated` field on the CSV (which retains its "last actual change" semantic).
